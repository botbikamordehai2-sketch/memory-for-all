# זיכרון לכולם

המאגר המאוחד של MOTI לזיכרון צוות, ממשל, סנכרון ותיעוד.

## מקורות
- `memory-for-all` — החומר הקיים נשמר ללא מחיקה.
- `github-sync` — נשמר תחת `github-sync/`.

## בטיחות
- אין API keys, tokens, passwords או secrets.
- שינויים משמעותיים דרך Pull Request.
- המאגרים המקוריים אינם נמחקים.
- `github-sync/.github/workflows/` נמצא בתת-תיקייה ולכן אינו workflow פעיל של המאגר המאוחד.
