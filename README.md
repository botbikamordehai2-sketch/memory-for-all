# זיכרון לכולם

המאגר המאוחד של MOTI לזיכרון צוות, ממשל, סנכרון ותיעוד.

## מקורות שאוחדו
- `memory-for-all` — החומר הקיים נשמר ללא מחיקה.
- `github-sync` — snapshot מלא של `main` נשמר תחת `github-sync/`.

## בטיחות
- אין API keys, tokens, passwords או secrets.
- שינויים משמעותיים נעשים דרך Pull Request.
- המאגרים המקוריים אינם נמחקים.
- `github-sync/.github/workflows/` נמצא בתת-תיקייה ולכן אינו GitHub Actions פעיל של המאגר המאוחד.
